실행 설정

선택한 모든 스위트에 적용

serial 스위트는 서버 전역 상태(결혼·마켓·보관함)를 쓰므로 병렬 단계가 끝난 뒤 클러스터 전체에서 하나씩 실행합니다.

실행마다 Agent가 봇 프로세스를 새로 띄우므로 스크립트 변경은 다음 실행에 바로 반영됩니다. 스위트 목록이 바뀌면 다시 읽기를 누르세요.

실행 설정

봇 수는 실행 중 변경 가능

Agent당 상한 0은 Agent가 알린 용량(--max-bots)을 씁니다. 지속 시간 0은 직접 중지할 때까지 실행합니다.

계정 번호는 Master가 Agent마다 process × 1,000,000 범위로 발급하고, 계정 세트는 그 안의 오프셋입니다. 같은 세트는 지난 실행의 캐릭터(레벨·장비)를 이어 쓰고, 새 세트는 1레벨부터 시작합니다.
