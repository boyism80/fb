# fb

fb is an open-source project for building and operating a 2D MMORPG game server.

It provides the server-side foundation for a persistent online game world—player sessions, in-game systems, and script-driven content such as quests, items, and NPC behavior. Design details, development guides, and scripting references are documented in the [project wiki](https://github.com/boyism80/fb/wiki).
