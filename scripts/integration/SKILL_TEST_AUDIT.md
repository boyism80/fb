# Skill Test Audit

## 1. 요약

| 항목 | 수치 |
|------|------|
| 스킬 스크립트 총계 | 294 |
| 테스트 등록 (고유) | 137 (46.6%) |

| 시나리오 모듈 | 16 |
| 병렬 봇 | 7 (bot0~6) |

### 핵심 문제

1. **의미 없는 테스트 다수** — `damage`/`damage_near`/`near_target` 등 40개+ 스킬이 시전자 MP(또는 HP)만 검증하고 **대상 피해·효과를 검증하지 않음**
2. **`target.lua` 8종** — `cast_until_ready`로 "외웠습니다" 메시지만 확인, **실제 효과(부활·해독·MP전달 등) 미검증**
3. **`buff.lua` 망각** — 등록은 되어 있으나 `target_type == MOB` 분기에서 **실제 시전·검증을 건너뜀**
4. **미등록 157종** — 플레이어 전투 스킬(용마제·용천제·금강퇴·백열장·용의제 등) 대부분 누락
5. **빈/TODO 스크립트** — 선풍각·소림둔갑술·환마술·혼돈 등은 테스트 추가 전 **스크립트 구현 필요**

## 4. 등록 스킬 상세 — 보강 필요 (수동 분석)

### 4.1 `target.lua` — P0 (효과 미검증)

| 스킬 | 스크립트 동작 (`spell/*.lua`) | 현재 테스트 | 갭 | 제안 테스트 |
|------|------------------------------|------------|-----|------------|
| 공력주입 | `spell.cast` 후 **타겟 MP += 시전자 전체 MP** (시전자 MP 0) | 외우기만 | MP 전달 없음 | 타겟 `bot(6)` MP 증가, 시전자 MP=0 확인 |
| 대지의빛 | `spell.cast` 후 대상 **스탯 팝업** (`MESSAGE_TYPE.POPUP`) | 외우기만 | 메시지 없음 | `resp.message` POPUP + 이름/레벨 문자열 포함 |
| 부활 | `STATE.GHOST` 타겟 → `STATE.NORMAL`, HP≥30 | 외우기만 | 유령 해제 없음 | 타겟 `state(GHOST)` 설정 → 시전 → `NORMAL`+HP 검증 |
| 시력회복 | `you:unbuff('절망')` | 외우기만 | 디버프 제거 없음 | 타겟에 `절망` 버프 부여 → 시전 → 버프 제거 확인 |
| 퇴마주 | `you:unbuff('저주')` | 외우기만 | 동일 | `저주` 부여 → 제거 확인 |
| 파혼술 | `you:unbuff('혼마술')` | 외우기만 | 동일 | `혼마술` 부여 → 제거 확인 |
| 해독 | `you:unbuff('중독')` | 외우기만 | 동일 | `중독` 부여 → 제거 확인 |
| 활력 | `you:unbuff('마비')` | 외우기만 | 동일 | `마비` 부여 → 제거 확인 |

### 4.2 `damage.lua` / `damage_near.lua` — P1 (피해 미검증)

20+20개 주문/뢰/화/백/자 계열 + 흡성대법·백열장·헬파이어.

| 그룹 | 스크립트 | 현재 | 제안 |
|------|---------|------|------|
| 단일 타겟 주문 20종 (`뢰진주`~`극진자천무주`) | `spell.damage(me, you, sp, {damage, mp})` — 고정 damage | 시전자 MP만 | 몬스터 HP = maxhp - damage 검증 |
| 근접 주문 20종 (`*'첨`) | `spell.damage_near` — 시전자 주변 | 시전자 MP만 | 주변 스폰 몬스터 HP 감소 |
| 흡성대법 | maxhp≤3000 몹만; **시전자 heal(min(damage, mob.hp))** + damage | HP+15 하드코딩만 | 약한 몹 스폰 → 시전자 HP 증가 + 몹 사망 |
| 백열장 | damage=280, mp=80 | MP만 | 몬스터 HP 검증 |
| 헬파이어 | damage=mp×1.5, `me:spell(sp):delay()` | expected_mp=0 (오류성) | `delay.lua`와 역할 분리; damage·delay 별도 검증 |
